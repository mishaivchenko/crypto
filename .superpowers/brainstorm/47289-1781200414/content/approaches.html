Settings Panel — выбери подход

Всё что сейчас разбросано по Dev Tools, Dashboard, Auto-Approval и верхней панели — нужно собрать. Три варианта как это организовать.

A

Settings Screen — отдельный экран в сайдбаре

Новая вкладка «⚙ Settings» рядом с Dashboard, Signals, Events, Trades. Внутри — четыре вертикальные секции: Engine, AI Advisor, Pipeline Automation, Global. Навигация по якорям внутри страницы.

Плюсы

  • Всё в одном месте, легко найти
  • Место для роста — легко добавить новые секции
  • Текущий Dashboard очищается от Dev Tools
  • Удобно для тюнинга — открыл и работаешь

Минусы

  • Новый экран — нужно обновить роутинг
  • Dev Tools уходят с Dashboard — нужна привычка
B

Правая панель (slide-in drawer)

Кнопка ⚙ в topbar открывает slide-in drawer справа. Внутри — те же секции. Dashboard остаётся, Dev Tools переезжают в drawer.

Плюсы

  • Не занимает место в сайдбаре
  • Доступна с любого экрана
  • Не ломает навигацию

Минусы

  • Drawer — паттерн уже используется для деталей трейдов/событий, может конфликтовать
  • Места меньше, чем у полного экрана
  • Неудобно для сложных форм (auto-approval rules)
C

Overview расширяется — секция «Control Panel» внутри Dashboard

Dev Tools, AI toggle, Auto-Approval, Engine runtime — всё переезжает в специальную секцию на Dashboard под текущими метриками. Auto-Approval остаётся своим экраном, но глобальный toggle переезжает на Dashboard.

Плюсы

  • Минимальные изменения структуры
  • Dashboard = command center — логично

Минусы

  • Dashboard и так перегружен
  • Не решает проблему «всё в одном месте»
  • При тюнинге нужно скроллить
